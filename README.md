# Biodata Ariyansyah

Situs ini adalah biodata pribadi statis yang siap di-deploy ke Vercel.

## Struktur file
- `index.html` — halaman utama
- `styles.css` — styling modern
- `w.jpeg` — foto profil

## Cara deploy ke Vercel
1. Buka terminal di folder `biodata`.
2. Jalankan `vercel` atau `vc deploy`.
3. Pilih folder ini sebagai root project ketika diminta.

## Catatan
- Pastikan semua file berada di root folder `biodata`.
- `index.html` sudah menggunakan `w.jpeg` sebagai foto profil.
